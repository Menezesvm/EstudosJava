## O que recrutadores devem saber

- Foco na linguagem: Java (conceitos fundamentais, POO, concorrência).


## Como avaliar meu trabalho rapidamente

1. Leia o README de cada projeto para entender o objetivo, a configuração e como executar os testes.Observe a cobertura de testes e os exemplos de entrada/saída para verificar a correção do código.

2. Analise o código em busca de convenções de nomenclatura consistentes, métodos pequenos e focados, e separação de responsabilidades.
Como executar (padrão).

3. Pré-requisitos: 
    - Java 11+ (ou versão específica do projeto),
    - Maven ou Gradle, Docker (opcional).

4. Comandos comuns:

   - Compilar com Maven: `mvn clean install`
   - Executar testes: `mvn test` ou `./gradlew test`
   - Executar a aplicação: `mvn spring-boot:run`    ou executar o arquivo JAR gerado: `java -jar target/<artifact>.jar`

- Consulte o README de cada projeto para verificar as versões e comandos exatos.
